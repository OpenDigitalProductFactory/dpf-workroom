# Contributing

Keep changes within this component and its declared ports. Preserve provenance and Apache notices. Run npm run check on the pinned toolchain; add meaningful affected ordinary/adverse behavior checks. Do not update provenance hashes just to make changed copied code pass: record the actual upstream/new implementation revision and compatibility delta. Shared compatibility snapshots must remain frozen until the canonical dependency migration is reviewed.

Use pull requests and signed-off commits. No credentials, customer data, local databases, host paths, generated caches or private operational evidence belong in commits. Report vulnerabilities privately through the repository owner's available private reporting channel; never post secrets in issues. GitHub Issues track this component; link dependent work across projects rather than duplicate its implementation backlog.
